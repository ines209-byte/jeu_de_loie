# jeu_de_loie
  ## **Développement d’un jeu de l’oie .**

Le Jardin des Oies est un jeu de l’oie interactif développé en HTML, CSS et JavaScript. Il reprend les règles classiques du jeu de l’oie en ajoutant des cartes d’action et des règles personnalisables.

  ## Fonctionnalités

- De 2 à 10 joueurs.
- Plateau de 63 cases avec cases spéciales.
- Lancement de deux dés et gestion des déplacements.
- Cartes d’action : Coup de pouce, Marche arrière, Bouclier et Échange.
- Personnalisation de certaines règles.
- Historique des déplacements.
- Sauvegarde et reprise d’une partie dans le navigateur.
- Tests fonctionnels intégrés.

  ## Technologies utilisées

- HTML5 et CSS3
- JavaScript ES6
- GitHub et GitHub Pages

  ## Évolutions possibles

Le jeu peut être amélioré par l’ajout de nouvelles cartes, de nouvelles actions et de nouvelles règles.

Les actions actuelles sont définies dans le code JavaScript. L’ajout de nouveaux effets nécessite de modifier les fonctions concernées.

  ## Lancer le jeu

Ouvrir le fichier `index.html` dans un navigateur ou publier le projet avec GitHub Pages pour y accéder en ligne.
